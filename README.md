# Tharun Ramisetty — Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## 1. Personalise before publishing
1. Add your profile photo to `assets/` and name it `profile-photo.jpg`.
   - Recommended: a clear portrait, square or 4:5 crop, JPG or PNG.
   - If using PNG, either rename it to `profile-photo.jpg` only after converting it to JPG, or update the image path in `index.html`.
2. In `index.html`, replace `YOUR_EMAIL@example.com` with your professional email address (there are two occurrences).
3. Check your GitHub and LinkedIn URLs and update them if needed.
4. Review the internship description and technical skills so they exactly match your experience.

## 2. Preview locally
- Open this folder in VS Code.
- Open `index.html` in a browser, or use the VS Code Live Server extension.
- No build tools or package installation are required.

## 3. Publish free with GitHub Pages
1. Sign in to GitHub and create a public repository named `tharun-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md` and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to deploy. Your site should be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/tharun-portfolio/`

## 4. Updating later
Edit the files, commit and push the changes to `main`. GitHub Pages will redeploy automatically.

## Notes
- The profile image is intentionally not included. Add your own photo as described above.
- The email is a placeholder until you replace it.
- Only include skills, dates, credentials and experience that you can confidently discuss in an interview.
